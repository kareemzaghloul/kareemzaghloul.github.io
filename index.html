PROJECT 01 / MECHANICAL DESIGN

Adjustable Proximity Sensor Mounting Bracket

An adjustable mounting system designed in SOLIDWORKS for an industrial M12 proximity sensor. The assembly includes a machined aluminum base plate, an L-shaped sensor bracket, and standard fastening hardware.

25 mm Linear adjustment range
M12 Industrial proximity sensor
2 Technical part drawings

The project includes a complete 3D assembly, exploded view, manufacturing-style drawings, and digital interference checks. The sensor uses manufacturer reference CAD. Physical manufacturing and testing have not been performed.
